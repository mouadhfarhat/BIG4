# Default admin account (Big4)

The app creates this admin **automatically** the first time the login screen loads (if no admin exists in the `user` table). You do **not** need to run any SQL by hand.

## Credentials

| Field    | Value            |
|---------|------------------|
| **Email**    | `admin@big4.com` |
| **Password** | `Admin@123`      |

## Usage

1. Open the app → login screen.
2. Choose **Admin** in the "I am a" dropdown.
3. Enter the email and password above.
4. Click **Log in**.

Admins cannot sign up; only Delivery Man and Client can create an account from the Sign up form.
